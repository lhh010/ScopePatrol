# CV PJ 设计:内镜清洗场景下的尺度悬殊目标检测

数据:`cleansight-yolo`(group1_large 35,090 帧 / group2_small 24,354 帧,train/val/test 按整段视频划分,互斥)
可复用管线:`E:\曦源\cleansight-yolo-pipeline`(00~04 编排脚本,ultralytics,MPS/CUDA/CPU 自适应)

## 一、任务定义
单模型/统一框架检测 6 类:
- 大目标:hand(手)、scope_control_body(内镜操控部)、scope_mid_section(内镜中部)
- 小目标:syringe(注射器)、short_brush(短毛刷)、scope_distal_end(内镜头端)

## 二、难点(用数据说话)
统计基于全量标签(train 采样 ~4000 帧 + val/test 全量):

| 类别 | 框数(约) | 面积中位数(占图%) | 备注 |
|---|---|---|---|
| hand | 28,806 | 2.44 | 高频类,常多实例、互相遮挡 |
| scope_control_body | 12,235 | 3.65 | 与 mid_section 同属一根镜体 |
| scope_mid_section | 10,442 | 3.18 | 细长形,长宽比极端 |
| syringe | 4,187 | 1.22 | |
| short_brush | 2,119 | 0.51 | 与 brush_tip_out 是部分-整体关系 |
| scope_distal_end | 8,090 | **0.30** | 极小,P90 也只有 0.39% |
| (brush_tip_out) | 561 | 0.62 | 类别极少,本次可只做分析不做检测 |

**难点 1:同一画面内尺度悬殊(中位数差 8~12 倍,尾部差 40 倍)。**
640 分辨率下 0.3% 面积 ≈ 20×20 像素,基础 FPN 的 P3(8× 下采样)几乎无信号。
**难点 2:类别严重不平衡**(hand 28.8k vs short_brush 2.1k,差 14 倍)。
**难点 3:部分-整体/相邻语义混淆**:brush_tip ⊂ brush、control_body vs mid_section 是同一刚性物体的两段,边界模糊,单帧局部特征不可分,需要上下文。
**难点 4:视频帧时序冗余与抖动**:每 4 帧取 1 帧,相邻帧高度相似,标注存在帧间跳变;同一目标时隐时现(遮挡、进出水)。
**难点 5:域内干扰**:水面反光、泡沫、水花、运动模糊、器械部分出画。

## 三、针对性设计(每个难点对应至少一个方法 + 一个实验)
1. **尺度悬殊 → 三种策略对比实验**(这是 PJ 的核心实验):
   a) baseline:单模型 6 类,yolo11s @640;
   b) 双模型分组(曦源现状):大/小目标两套权重;
   c) 单模型 + **P2 检测头**(4× 下采样)+ 高分辨率 960/1280 训练;
   d) 单模型 + **切片推理(SAHI 式 tile + 合并)**。
   评价指标:各类 AP、AP_small、推理 FPS、参数量 —— 论证"分组训练"是否只是工程妥协。
2. **类不平衡 → copy-paste 小类增强 + 类别加权采样**;报告每类 AP 提升曲线。
3. **部分-整体混淆 → 结构化后处理**:利用 brush_tip ⊂ short_brush 的包含关系做 hierarchical NMS / 逻辑一致性约束(子框存在才允许父框过阈值降低);对 control_body–mid_section 做"同镜体"共线/连接先验。
4. **时序冗余 → 帧级检测 + 轻量跟踪(ByteTrack)平滑**,提出**时序一致性指标**(相邻帧类别跳变率、ID switch),这是静态 COCO 评测不覆盖的维度。
5. **极小目标评测协议**:AP_small 按 area<32² 单独汇报,证明改进不是来自大类。

## 四、可行性
- 数据量充足(6 万帧、含标注),划分按整段视频,无泄漏;
- 管线现成:曦源 `03_train.py`/`04_validate.py` 可直接改用,只需把两组合并成统一 6 类数据集(新写一个 build 脚本);
- 训练算力:本机无 NVIDIA GPU。方案:Colab T4/AutoDL 3080 租用,yolo11s@640 约 1~2 h/组,P2+960 约 4~6 h,总预算 < 50 元即可完成全部对比实验;
- 风险:P2 头在小数据上过拟合 → 用冻结 backbone 微调与预训练权重兜底;最坏情况退化为 baseline + 双模型分组,也能交付完整对比故事。

## 五、创新点表述(可直接写进报告)
不是"换个任务跑 YOLO",而是:
1. 系统研究**同图 40 倍尺度悬殊**下的检测策略(分组双模型 vs P2 头 vs 切片推理)并给出量化结论;
2. 提出**层级化后处理**利用部分-整体标注结构(brush_tip⊂brush)提升细粒度小类;
3. 引入**时序一致性评测**弥补单帧 mAP 对视频检测的盲区。
